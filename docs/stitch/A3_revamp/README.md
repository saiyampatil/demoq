# Stitch A3 design reference

Visual reference for the A3 Report page (header, tabs, outputs strip, "In this report" rail, Executive summary, Concept results, Findings by guide section, How people sounded, Tensions, Where the evidence is thin, Sources drawer, footer).

- Reference only. Never imported by the app.
- Any `DESIGN.md` in this folder is not applicable. The HTML export and the PNG are the visual source.
- It is a static design, one frame. It does not show clicks, hovers, popovers, other drawer variants, Edit, Client preview, or empty, Out of date and error states.
- Numbers, names, IDs and quotes in the frame are placeholders. Some labels and layouts are wrong. The rules in `CLAUDE.md`, `docs/OPEN_QUESTIONS.md` and the A3 revamp brief win over the pixels.
- Open `code.html` in a browser to see the frame (it loads Tailwind from a CDN). `screen.png` is a screenshot of it.
