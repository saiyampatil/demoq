# Stitch A2 design reference

Visual reference for the A2 "Emotion & behaviour" screen (Themes, Concepts, Tensions, Review mode).

- Reference only. Never imported by the app.
- `silk/DESIGN.md` is not applicable. The HTML exports and the PNGs are the visual source.
- Numbers, names, IDs and some labels in the frames are examples and some are wrong. The rules in `CLAUDE.md`, `docs/OPEN_QUESTIONS.md` and `docs/stitch/ICE_CREAM_MOCK_DATA.md` win over the pixels.
- Open an HTML file in a browser to see a frame (it loads Tailwind from a CDN).
